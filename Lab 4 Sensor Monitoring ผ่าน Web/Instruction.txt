LAB 4 Sensor Monitoring ผ่าน Web : 5 คะแนน

คำแนะนำการทดลอง (Instruction):
1. แก้ไขค่า ssid และ password เป็นของเครือข่าย WiFi 2.4 GHz
2. ต่อสายเซนเซอร์ DHT11 หรือ DHT22 ที่ขา GPIO 4
3. กำหนดประเภท DHTTYPE ให้ตรงกับฮาร์ดแวร์ที่ใช้ (DHT11 หรือ DHT22)
4. อัปโหลดโค้ดลง ESP32 และเปิด Serial Monitor ที่ Baud Rate 115200
5. เปิดหน้าเว็บตาม IP Address และปล่อยทิ้งไว้ หน้าเว็บจะรีเฟรชค่าใหม่โดยอัตโนมัติทุก 3 วินาที
